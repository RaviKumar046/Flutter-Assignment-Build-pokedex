3. FAVORITES - MOST IMPORTANT REQUIREMENT
=========================================

This is the main technical requirement.

Favorite state must:

1. Persist locally on the device.
2. Work across ALL screens.
3. Update immediately without manual refresh.
4. Have ONE single source of truth.

Example:

List Screen:
Pikachu ❤️

Open Detail Screen:
Pikachu ❤️

Tap heart:
Pikachu ♡

Go back to List:
Pikachu ♡

The list must already reflect the changed value.

Likewise, if a Pokémon is favorited/unfavorited from the List screen, the Detail screen and Favorites screen must use the same state.

DO NOT maintain separate favorite states inside individual screens.

Use a centralized state-management solution.

Recommended simple implementation:

* Provider + ChangeNotifier for shared favorite state
* SharedPreferences for local persistence

You may use another lightweight solution only if you have a strong reason. If you choose something else, explain why in README.md.
